Project NerdNest

A simple way for gamers, nerds, and anyone interested to find LFG groups in real life. 

## MVP (only these for v1)
1) Profiles with interests + neighborhoods
2) LFG posts (create & browse, with tags like “D&D 5e”, “Beginner-friendly”)
3) Events list + RSVP (venues only, no exact addresses)

## Non-goals (not in v1)
- Real-time chat
- Complex matchmaking
- Multi-city support

## Tech (planned)
React (frontend) · Express/Node (API) · MongoDB (DB)

**Success for v1:** A new user can: create a profile → post or find 1 LFG/event → message via provided contact method (e.g., Discord tag).
